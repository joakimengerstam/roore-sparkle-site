# Roore service landing page

## Goal
Create a polished Swedish landing page that keeps Roore’s restrained, trustworthy brand while making the offer, target audience, process, and contact action immediately clear.

## What will be built
- A compact navigation with clear links to services, approach, customer fit, and contact.
- A first screen centered on Roore’s promise: repetitive order and invoice work can be removed without replacing existing systems.
- A visual live-workflow panel that shows automation preparing work while people retain approval.
- A service overview for invoices/bookkeeping, orders/quotes, email/cases, integrations, reporting, and documents.
- A clear “who we help” section focused on operations-heavy teams using Fortnox, Visma, Bokio, email, and business systems.
- A simple three-step engagement model: short conversation, one workflow, then measurable expansion.
- A strong contact section using Roore’s existing public email and a prefilled 15-minute enquiry link.
- Responsive navigation and layouts for phone, tablet, and desktop.

## Design direction
- Preserve the existing off-white, forest-green, understated Scandinavian visual language.
- Use a stronger editorial hierarchy, compact mono labels, precise borders, and operational status details.
- Avoid generic stock imagery; use Roore’s actual workflow as the main visual story.
- Add subtle entrance and status animations with reduced-motion support.

## Technical details
- Build the page at `/` with semantic sections and one H1.
- Add reusable semantic color and typography tokens in the global stylesheet.
- Add route-specific title, description, Open Graph, and Twitter metadata.
- Keep contact actions as email links so the page is fully functional without introducing data storage.
- Verify the finished page at desktop and mobile widths and check for runtime/build errors.
